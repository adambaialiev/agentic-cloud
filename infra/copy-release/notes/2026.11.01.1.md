# Email set up from the Workspace, and auto-merge

## What's new

- Email is set up after the install, from the Workspace: an admin opens Mail, gives a Resend key or any provider's SMTP settings, and the Workspace makes the mail receiver, shows the DNS records to add, checks them and turns mail on. Everything else works before that.
- Auto-merge: each person can turn it on in the Workplace window. Their agents' proposals that are ready and pass their checks then merge by themselves, recorded as automatic rather than as approved.
- Each conversation's latest turn ends with a one-line recap, like the terminal's.
- Files in a chat have no size limit.

## Fixed

- When Fly's registry briefly refuses an image during an install or upgrade, the installer asks again instead of stopping, and a rerun carries on from where it stopped.
- The email setup's longer lines wrap instead of being cut off.

## Needs you

- Nothing. A mail receiver an older installer made is found and kept.
