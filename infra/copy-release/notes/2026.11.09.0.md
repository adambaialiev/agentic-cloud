# An upgrade screen that shows its time, and fixes from our own run through an install

## What's new

- The upgrade screen shows how long each step has been running, ticking while it works, and ends on a Done button.
- Before you upgrade, the screen says how long your last upgrade took, instead of a fixed guess. Before your first one it says 5 to 15 minutes, most of it copying the release in.
- The Chief of Staff chat fetches only what has changed since it last looked, so it stays quick on a slow connection.

## Fixed

- An admin who started signing in to Claude and did not finish no longer loses the Upgrade button. The card says so and offers "Cancel my Claude sign-in". Someone else's open sign-in still waits.
- The age of your last database backup survives a restart: This copy and the daily report read it from storage, so both show the same, real age.
- The daily report's counts of agents and their work leave out the Workspace's own agents, such as the Chief of Staff, just as your list of agents does.
- When an agent's computer stops answering, its turn or stop no longer hangs: after two minutes it ends and says why.
- The Chief of Staff chat and Messages no longer break or freeze when a refresh is lost or hangs. They try again quietly.
- The installer's plan, for an install run with an organization token, now says the backend keeps that token, instead of listing a second token the install never makes.
- A note an agent has just picked up shows who is working on it straight away, instead of reading "Unclaimed" for a few seconds.

## Needs you

- Nothing.
