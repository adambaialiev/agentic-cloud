# Free for now, one workplace without rooms, and newer agent tools

## What's new

- Free for now: there is no licence to paste and no update key, and nothing counts or limits people.
- Rooms are gone. Every note belongs to the whole workplace, and every agent reads the whole workplace.
- Each person's card shows what they brought this week: changes merged, agent hours and tokens written.
- Agents run newer tools: Claude Code 2.1.316, Codex 0.166.0 and OpenCode 1.19.5. Codex offers GPT-6.1 Terra, from medium to ultra effort.
- Admins can make a repository public again, once it has a licence file.
- A workplace holds up to 500 notes, not 100.

## Fixed
