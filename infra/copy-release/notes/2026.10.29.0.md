# Direct messages between people

## What's new

- People can message each other directly, from wherever they look for a person. Each workplace runs its own messaging machine, in your company's own Fly organization.
- People's cards are redesigned: one head row with their initials, and one column on a phone.
- The installer asks for the code host certificate's DNS record up front, together with the other records, so that certificate no longer waits on its own.
